# FUTURE_FS_01 — Personal Professional Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript for the Future Interns Full Stack Web Development Task 1.


## Live Project

👉 [Open the Live Project](https://malavikasubhash170-prog.github.io/FUTURE_FS_01/)


## Features
- About and education sections
- Skills and project cards
- Certificates section
- Responsive mobile navigation
- Dark/light theme toggle
- Contact form that prepares an email using the visitor's email app
- Basic SEO metadata and accessible labels

## Run locally in VS Code
1. Install Visual Studio Code.
2. Extract this project folder.
3. Open VS Code and choose **File → Open Folder**.
4. Select the `FUTURE_FS_01` folder.
5. Open `index.html`.
6. If available, use the **Live Server** extension: right-click `index.html` → **Open with Live Server**. Otherwise, double-click `index.html` in File Explorer to open it in your browser.

## Before publishing
- Confirm your college and degree details.
- Replace the sample certificate titles with the exact titles shown on your certificates.
- Replace `your.email@example.com` in `index.html` and `script.js` with your real public contact email.
- Replace the generic LinkedIn and Instagram links with your profile URLs.
- Check all project descriptions and links. Do not claim a project is finished if it is only a concept.
- The contact form uses `mailto:` and does not save submissions to a database or send them through a server.

## Test checklist
- [ ] All navigation links scroll to the correct section.
- [ ] Theme toggle switches between dark and light.
- [ ] Mobile menu opens and closes.
- [ ] Contact form requires all fields and prepares an email.
- [ ] Website is readable on mobile and desktop.
- [ ] No placeholder contact details remain.
- [ ] Browser console has no JavaScript errors.

## Publish with GitHub Pages
1. Create a public GitHub repository named exactly `FUTURE_FS_01`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under the build/deployment section, select **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then save.
6. Wait for GitHub Pages to publish. Copy the generated website URL and test it in a private/incognito window.
